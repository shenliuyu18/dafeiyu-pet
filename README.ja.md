デスクトップをあちこち泳ぎ回る「青い大肥鱼（大肥魚）」の小さなデスクトップペットです。彼女はあなたのマウスに向かって身を傾け、掴まれて振り回され、お腹が空くと元気がなくなり、暇になるとぶつぶつ独り言を言い、さらに家計簿までつけます：**彼女が食べた白ごはんは、あなたの各 AI プラットフォーム口座の残高そのものなのです。**

- **106 個のコマ送りアクション**：待機、白ごはんを食べる、コードを書く、ルービックキューブ、花火、中秋の名月鑑賞、クリスマスツリーの飾り付け……
- **9 種類の選択可能なキャラクター**：大肥鱼、GPT娘v1、GPT娘v2、そして Claude、Gemini、GLM、Grok、Kimi、Qwen の 6 体の AI 娘。
- **144 枚のミーム画像**：定番ミーム + 青い大肥鱼アーカイブの厳選 + dsh-meme ギャラリー + DSniang1、1 枚ごとにキャプション付き。
- **キャラクターストア**：8 個のダウンロード可能なキャラクター + 大肥魚 plus 拡張パック。オンラインダウンロード、ローカル zip のインポート、いつでもアンインストールに対応し、ダウンロード時は最速のミラーを自動選択します。
- **大肥魚 plus**：167 個の新アクション。インストールするとアクションプールが 268 個に拡張され、キャラクター枠を余計に消費しません。
- **白ごはん家計簿 / ポモドーロ / カスタムインタラクション文言 / 全画面回避 / 自動起動**。すべてのデータと API Key は本機に留まります。
- **中 / 英 / 日 の 3 言語**：UI ナビゲーション、右クリックメニュー、435 条のキャラクターセリフとミームのキャプションを切り替え可能。設定に追従して即座に反映されます。
- **フル版と Lite 版**：機能は同一で素材の仕様が異なり、同時インストール・同時実行が可能です。

技術スタックは **Wails v2 + システムの WebView2**：Chromium を同梱しないため、インストールサイズが小さくメモリ使用量も少なく、素材とデータは本機に留まります。プログラムコードは MIT でオープンソース化されています。

### フル版か Lite か？

| | フル版 | Lite 版 |
| --- | --- | --- |
| 内蔵アニメーション | 106 個の 640×360 オリジナル VP9-alpha WebM | 480×270 VP9-alpha 圧縮 |
| ダウンロード可能なキャラクターパック | 640×360 VP9、CRF 32 + sharpness 2 | 480×270 VP9、CRF 42（自動選択） |
| 表情立ち絵 / ミーム画像 | オリジナル画像 | 圧縮 WebP |
| 効果音 / フォント / センシティブ語リスト / ミーム | 保持 | 保持 |
| 機能 | 完全に同一 | 完全に同一 |

フル版の内蔵素材は元のバイト列のまま store-only の `assets.zip` に格納されます。Lite 版は `tools/build-lite-assets.py` によって別途 `assets-lite/` に生成され、フル版の素材を上書きすることはありません。キャラクターパックはインストーラーに同梱されず、初回使用時に必要に応じてダウンロードされます。

### インストール先

- フル版：`%LOCALAPPDATA%\Programs\大肥鱼桌宠`
- Lite 版：`%LOCALAPPDATA%\Programs\大肥鱼桌宠 Lite`

両版は独立したインストールディレクトリ、状態ディレクトリ、単一インスタンスを使用するため、同時インストール・同時実行が可能で、互いに影響しません。

### インストールのヒント

- **WebView2 がない場合**：インストーラーが自動でダウンロードしてインストールします（ネット接続が必要）。
- **SmartScreen が「不明な発行元」と表示する**：インストールパッケージにコード署名がないためです。「詳細情報」→「実行」で続行できます。
- **Electron 旧版（1.3.0 以前）からのアップグレード**：まず「Windows の設定 → アプリ」で旧版をアンインストールしてから、新版をインストールしてください。1.4.0 以降、リポジトリにも本機にも Electron のコードとランタイムは含まれていません。

## キャラクター

設定 → キャラクターと効果音 でいつでもキャラクターの切り替え・ダウンロード・アンインストールができ、切り替えると即座に反映され、選択内容が記憶されます。

| キャラクター | 種類 | 内容 |
| --- | --- | --- |
| 大肥鱼 | コマ送りアニメーション | 106 個の 640×360 VP9-alpha 透過 WebM（デフォルト、内蔵） |
| 大肥鱼 plus | 拡張パック | 167 個のアクションを大肥鱼に統合、アクションプール 106 → 268、キャラクター枠を余計に消費しない |
| GPT娘v1 | スプライトシートアニメーション | 73 フレームの透過スプライトシート。待機、走る、手を振る、作業、待機中、祝福、16 方向の視線に対応 |
| GPT娘v2 | コマ送りアニメーション | 92 個のアクション、オンデマンドでダウンロード |
| Claude / Gemini / GLM / Grok / Kimi / Qwen | コマ送りアニメーション | それぞれ 92〜166 個のアクション、オンデマンドでダウンロード。それぞれ独自のペルソナセリフあり |

キャラクターパックはストアから必要に応じてダウンロードでき、ローカルの `.zip` インポートといつでもアンインストールに対応しています。ダウンロードは直結と複数の高速ミラー（ghfast、gh-proxy、ghproxy）を内蔵し、まず各回線の速度を計測して最速のものを選び、ある回線が失敗すると自動で次に切り替えます。自作のキャラクターパックは [docs/形象包制作标准.md](docs/形象包制作标准.md) に従ってパッケージ化してください。付属の `tools/character-pack/validate.py` と `make_pack.py` も利用できます。

大肥鱼以外のキャラクターは、それぞれの AI 娘ペルソナのインタラクション文言を使用します（Claude の規則、Gemini の猫娘、GLM の狐娘、Grok の口の悪さ、Kimi の長文、Qwen のお嬢様）。白ごはんネタやミーム画像はなく、家計簿は「使用量帳簿」として表示されます。

## 白ごはん家計簿

右クリックメニューまたはトレイから開きます。設定で AI プラットフォームを選び API Key を設定すると、そのアカウントの「利用可能残高 / 付与残高 / チャージ残高」を表示します（OpenAI / Claude は今月の利用額・直近7日・今日の費用）。

- **API プラットフォーム**：DeepSeek、Kimi、SiliconFlow、OpenAI、Claude。Kimi / SiliconFlow は国内サイトで認証に失敗すると自動的に国際サイトへ切り替え、通貨も変更します。OpenAI / Claude は Admin Key が必要で、OpenAI は API 利用料のみを集計し ChatGPT サブスクは含みません。
- **環境変数**：画面で Key を設定していない場合、`DEEPSEEK_API_KEY` / `MOONSHOT_API_KEY` / `SILICONFLOW_API_KEY` / `OPENAI_ADMIN_KEY` / `ANTHROPIC_ADMIN_KEY` も使用します。
- **Key の安全性**：API Key は Windows DPAPI で暗号化して本機の状態ファイルに保存され、現在の Windows アカウントだけが復号できます。問い合わせ時は該当プラットフォームの公式 API にのみ送信されます。共用の PC では入力しないでください。リスクは自己責任です。

**白ごはんネタ小辞典**：白ごはん = あなたの Token をこっそり食べる；残りごはん = キャッシュ；外注サボり = 別の Agent に仕事をさせる；定時退社して食事 = 推論完了。

## 表情とアニメーション

**表情ライブラリ**：定番ミーム 20 枚 + 青い大肥鱼アーカイブ厳選 59 枚 + dsh-meme 重複除去ギャラリー 64 枚 + DSniang1、合計 144 枚で、いずれも画面に合ったキャプションが 1 つ付いています。定番ミームとアーカイブ / dsh ギャラリーはすでに 1 つのシーンプールに統合され、シーンごとにシャッフルして連続重複を避けます。

**アニメーション状態機械**：22 個のコアアニメーションが状態に応じて切り替わります（待機の呼吸 / 浮遊ステップ / カニ歩き / キョロキョロ / クリック応答 ×5 / 白ごはんを食べる / Token を食べる / おやつをがっつく / うたた寝 / うなだれてため息 / 跳ねて祝福 / コードを書く / 残高を数える）。さらに 84 個の暇つぶし小演目があります。文字入りのアニメーション（`是啊，吃什么` / `深度思考碎碎念`）は左右反転の対象外で、文字が鏡像になるのを防ぎます。

**満腹度**は時間とともにゆっくり低下し、32 を下回ると元気がなくなり、泳ぎが遅くなり、ごはん茶碗が空になります。給餌すると満タンに戻り、機嫌も上がります。

**ポモドーロ**：集中を開始すると、彼女は画面の隅へ泳いでカウントダウン札を掲げ、静かに付き添います。その間は他の自動アクションを実行せず、各作業アクションを最後まで再生してから設定した間隔だけ休んで次を再生します。右クリックの「アクションを選ぶ」などの手動操作は引き続き可能です。時間になると画面中央へ泳いで戻り、跳ねて休憩を知らせます。カウントダウン札が画面の下端に接すると自動で魚の体の上側へ回り込み、タスクバーに隠れません。

## データの保存場所

`%APPDATA%\dafeiyu-desktop-pet\dafeiyu-state.json`（Lite 版は `%APPDATA%\dafeiyu-desktop-pet-lite`）に、満腹度、機嫌、位置、サイズ / 待機位置 / ポモドーロの時間と作業アニメーションの間隔 / 白ごはん家計簿のオンオフ / 自動起動 / 一緒に起動するアプリ / カスタム文言、さらに任意の API Key（DPAPI 暗号化）が保存されます。ダウンロードしたキャラクターパックは `characters/` サブディレクトリに解凍され、アンインストール時は該当ディレクトリを直接削除します。

## キャラクターパックと自作

- ストアのカタログは [dafeiyu-pet-assets](https://github.com/shenliuyu18/dafeiyu-pet-assets) が提供し、9 個のダウンロード可能なパックとカバー画像を含みます。カタログも zip も GitHub 上にあり、第三者のネットディスクは経由しません。
- フル版のパックは 640×360 CRF 32 の透過 WebM、Lite 版のパックは 480×270 で、すべて alpha チャンネル付きです。
- ダウンロード時は直結と ghfast / gh-proxy / ghproxy の間で最速の回線を計測し、失敗すると自動で切り替えます。
- 自作パック：[docs/形象包制作标准.md](docs/形象包制作标准.md) に従って `manifest.json` とアニメーションファイルを用意し、`python tools/character-pack/validate.py <ディレクトリまたはzip>` で検証してから `make_pack.py` でパッケージ化します。アプリ内の「キャラクターパックをインポート」でも id、パス、ファイル、スロット参照を再度検証します。

## 開発と実行

前提：Node.js、Go 1.25+、Wails CLI v2.16+、NSIS 3.x、Windows 標準またはインストール済みの WebView2。

プロジェクトに npm の実行時依存はなく、ビルドスクリプトは Node の組み込みモジュールのみを使用し、本機のユーザーディレクトリにある Go / Wails / NSIS ツールチェーンを自動的に PATH に追加します。

```bash
npm run build              # フル版 → dist/dafeiyu-pet-<バージョン>-setup.exe
npm run build:lite         # Lite 版（圧縮素材を自動生成）→ dist/dafeiyu-pet-lite-<バージョン>-setup.exe
npm run packs:lite         # 素材リポジトリ用の Lite キャラクターパックを生成 → characters-build/lite/
npm run dist-install       # フル版をビルドし、本機へサイレントインストールして起動
npm run dist-install:lite  # Lite 版をビルドし、本機へサイレントインストールして起動
npm run perf:check         # 分離起動して起動時間/メモリ/CPU/ディスク書き込みの予算をサンプリング → perf-report.json
npm run test:frontend     # フロントエンドの純粋ロジック単体テスト（node:test、追加依存なし）
```

日常のデバッグでは `wails/` に入って直接 `wails dev` を実行することもできます。起動すると彼女は画面の右下に現れ、トレイアイコンからいつでも呼び出したり隠したりできます。

実機でのパフォーマンス検証には `--isolated` が使えます。独立した状態ディレクトリ（`dafeiyu-desktop-pet-isolated`）、単一インスタンス、ウィンドウクラス名を使用し、本機に既にインストールされたバージョンと同時に実行でき、正式な設定・自動起動・更新には影響しません。

`--dev-debug` を付けて起動すると、本機の `127.0.0.1:9336` のみをリッスンするデバッグブリッジが追加で開きます：`/state` でウィンドウ / Region の状態、`/mem` でヒープと素材の統計、`/fullscreen` で回避の判定と直近 40 回の判定記録、`/ledger` で家計簿の診断（`?refresh=1` を付けると即座に再問い合わせ）、`/js` でページに直接 JS を注入でき、インタラクションの不具合調査に便利です。

リポジトリには GitHub Actions が含まれています：push / PR ではバージョン番号の整合性チェック、スクリプトの構文、gofmt、`go vet`、`go test`、コンパイル検証が実行されます。`v*` タグを付けるとフル版と Lite 版が自動ビルドされ、`SHA256SUMS.txt` が生成されて Release が作成されます（リリース前に `package.json` のバージョンを更新しておいてください。タグと一致しないとそのまま失敗します）。Release を手動でトリガーする際は完全なタグを入力する必要があります。`-` を含むタグは自動的にプレリリースとしてマークされます。

## パッケージング

- フロントエンドは `tools/wails-prepare.js` が `renderer/` + `assets/`（フル版）または `assets-lite/`（Lite 版）から生成します：HTML / JS / CSS の相対パスを書き換え、素材を `assets.zip` に格納し、Wails が仮想ファイルシステム経由で読み取って動画の Range リクエストにも対応します。フル版は store-only で元のバイト列を維持します。
- `tools/wails-build.js` はバージョン番号の同期、Wails 呼び出しによる NSIS インストーラーのビルド、`dist/` へのコピーを担当し、`--lite` / `--install` に対応します。
- インストーラーは `-webview2 download` を使用します：WebView2 の不足を検出するとダウンロードしてインストールします。インストールウィザードは簡体字中国語です（NSIS `SimpChinese`）。
- リリースアセットの名前は `dafeiyu-pet-<正式バージョン>-setup.exe` / `dafeiyu-pet-lite-<正式バージョン>-setup.exe` で、更新チェックは `setup.exe` の接尾辞と lite の識別子から対応するバージョンを選択します。
- **バージョン番号の約束**：バージョン番号は `package.json` で管理し、リリース時に CHANGELOG / README / インストーラー名へ同期します。Wails の Windows ファイルバージョンは数値セグメント（例 `1.5.3.0`）を使用し、アプリ内のバージョン情報ページと更新チェックは完全なバージョン番号を使用します。
- **更新パッケージの検証**：クライアントはインストーラーをダウンロードした後、`SHA256SUMS.txt` を強制的に検証し、ハッシュが一致しない場合はファイルを削除して実行を拒否します。マニフェストがない場合は自動更新が無効になり、手動ダウンロードのみ可能です。ダウンロードとインストールは同じ検証を通ります。
- **任意の署名**：リポジトリの Secrets に `UPDATE_SIGNING_KEY`（Ed25519 秘密鍵 PEM の base64）と `UPDATE_SIGNING_PUBKEY`（公開鍵の生 32 バイトの base64）を設定すると、CI が `SHA256SUMS.txt.sig` を生成し、ビルド時に公開鍵を注入します。クライアントは署名検証に失敗すると更新を拒否します。鍵ペアは `node tools/update-keys.js` で生成し、秘密鍵は Secrets にのみ置いてください。

## 実装のポイント

- **透過ウィンドウとクリック透過**：`WindowIsTranslucent: true` + `BackdropType: None` により WebView2 が本当にデスクトップを透かします。`WS_EX_NOACTIVATE` はデフォルトでフォーカスを奪わず、設定を開くときに解除して `SetForegroundWindow` を呼び、閉じると元に戻します。全画面ウィンドウでは動的 Region（`SetWindowRgn`）でペット本体と完全な吹き出し / ミーム / 帳簿 / カウントダウン札の領域を保持し、メニュー・設定・ドラッグ時はウィンドウ全体に戻します。パネルとフォーカスの呼び出しは直列化し、パネル表示前に Region を広げ、閉じた後は 260 ms 待ってから Region を縮めます。フロントエンドの JS/CSS にはバージョン番号を付け、WebView2 が古いキャッシュを使うのを防ぎます。
- **素材を一切変更しない（フル版の内蔵素材）**：`assets.zip` は store-only で書き込まれ、動画、立ち絵、ミーム、フォント、効果音のバイト列はソースファイルと一致します。Wails は `zipFS` 経由で仮想ファイルシステムを提供し、動画の Range リクエストが利用できます。ダウンロード可能なキャラクターパックは別途トランスコードした CRF 32 素材です。
- **フロントエンド構造**：`renderer/` が唯一の UI ソースです。`wails/frontend/api.js` がそれを Wails のバインディング/イベントにマッピングし、メインウィンドウ内にフォーカス可能な API Key / カスタム文言編集カードを提供します。
- **ウィンドウ**：ワークエリア全体を覆う、透過・最前面・フォーカスを奪わないウィンドウで、キャラクターは CSS `transform` でウィンドウ内を泳ぎます（GPU 合成）。初期バージョンは「小さなウィンドウ + setPosition で追従」方式でしたが、150% DPI で 1 px のサイズずれが累積するため、全画面キャンバス方式に変更しました。
- **キャラクター素材**：VP9-alpha の透過 WebM をそのまま `<video>` で再生します（Chromium は alpha チャンネルをネイティブにサポート）。素材キャンバスは 640×360 で、キャラクターは中央に約 226×282 の大きさで配置され、周囲は透明です。CSP で `media-src` と `font-src` を許可しないと、動画とフォントが `default-src 'none'` にブロックされます。
- **アニメーション状態機械**：`applyBase()` は「ドラッグ > 睡眠 > ポモドーロ > 空腹 > 移動 / 待機」の優先順位でループアニメーションを選択します。クリック、給餌、帳簿などの単発アクションは `playOnce()` を通り、再生後に自動で基本状態へ戻り、タイムアウトのフォールバックもあります。
- **キャラクターパック**：カタログは素材リポジトリに保存されています。ダウンロード前にミラーを計測し、zip 内の `manifest.json` は schema、id、パス、スロットの検証を経てからユーザーディレクトリへ原子的に解凍されます。内蔵キャラクターとプラグインパックは同じリソースオーバーレイを共有します。
- **サイズ拡大縮小**：キャラクターパックは `#scale` 内で全体を CSS `scale` し、ヒットボックス、移動境界、Wails の透過判定を比率に応じて換算するため、0.6×–1.6× のどの段階でもドラッグ/クリックが正確です。
- **パフォーマンス基準**（分離インスタンスでの実機計測、`docs/后续开发方案.md` を参照）：コールドスタート約 0.83 s。静かな待機でシングルコア約 9.6%、泳ぎ回りでシングルコア約 23%（45fps）。状態は 1 分ごとにまとめて書き込み。メインプロセスのプライベートメモリ約 85 MB、WebView2 子プロセスの合計約 200 MB（ウィンドウサイズと DPI により変動）、Go の生存ヒープ約 27 MB。ウィンドウ非表示、全画面回避、最小化のときは動画デコードを一時停止します。

## よくある質問

**開かない、または白い画面しか表示されない？** まずシステムに Microsoft Edge WebView2 Runtime がインストールされているか確認してください。インストーラーが自動でダウンロード・インストールします。Microsoft の公式サイトから手動でインストールしてからペットを再起動することもできます。

**キャラクターパックのダウンロードが遅い、または失敗する？** アプリは直結と複数のミラーの間で最速の回線を自動選択します。どれも通らない場合は、しばらくしてから再試行するか、[dafeiyu-pet-assets](https://github.com/shenliuyu18/dafeiyu-pet-assets) から zip を手動でダウンロードして、ストアの「キャラクターパックをインポート」から読み込んでください。

**Windows 10 でデスクトップ全体がぼやける？** 1.4.8 で修正済みです：旧版は 22621 より前のシステムで Aero のすりガラス効果にフォールバックし、ウィンドウがワークエリア全体を覆うためデスクトップ全体がぼやけていました。新版はこのレイヤーを直接取り除き、デスクトップは鮮明なままです。万一お使いのマシンで背景が黒くなった場合は、**トレイアイコンを右クリック →「Win10 背景のぼやけを修正」のチェックを外す**とすぐに旧動作へ戻せます（状態ファイルの `"blurFix"` を `false` に変更する方法もあります）。

**「不明な発行元」の警告は出ますか？** 出ます。インストールパッケージにコード署名がないため、SmartScreen がブロックする可能性があります。「詳細情報」→「実行」をクリックしてください。

**フル版と Lite は同時にインストールできますか？** できます。両版はインストールディレクトリ、状態ディレクトリ、単一インスタンスの識別子がすべて独立しているため、同時に実行できます。

**完全にアンインストールするには？** 「Windows の設定 → アプリ」でアンインストールした後、設定と Key も消したい場合は `%APPDATA%\dafeiyu-desktop-pet`（Lite 版は `%APPDATA%\dafeiyu-desktop-pet-lite`）を削除してください。

**全画面で動画を見ているときも彼女は表示されたまま？** 設定 → 待機と自動アクション → 全画面動画 / ゲーム で有効になっているか確認してください。通常のウィンドウや最大化ウィンドウでは非表示になりません。

**カスタム文言が保存できない？** 保存時にオフラインのセンシティブ語リストでチェックされ、センシティブ語を含む行はブロックされます。1 行あたり最大 40 文字、最大 20 行です。

**更新チェックに失敗する？** GitHub へのアクセスが不安定な場合は、しばらくしてから再試行するか、Releases からインストーラーを手動でダウンロードして上書きインストールしてください。設定は保持されます。

## 旧バージョンについて

1.4.0 以降は Electron 版を提供していません：リポジトリには Electron のメインプロセス、プリロードスクリプト、旧編集ウィンドウ、electron / electron-builder の依存もなく、フォールバックビルドもありません。本機に 1.3.0 以前の Electron 版がまだインストールされている場合は、まず「Windows の設定 → アプリ」でアンインストールしてから新版をインストールしてください。
