# 本地化说明

桌宠支持简体中文、English、日本語。安装器与应用首次启动按 Windows 显示语言自动选择（中文 / 日语，其余默认英语），之后可在 **设置 → 关于 → 语言 / Language** 切换，立即生效并保存到本机状态。

## 覆盖范围

| 内容 | 位置 | 状态 |
| --- | --- | --- |
| 右键菜单、设置页导航与小节标题、按钮、说明文字与运行状态提示 | `renderer/lib/i18n.js`（引擎）、`renderer/lib/ui-i18n.js` | 已覆盖，含动态数字/单位/错误前缀 |
| 内置与下载包/扩充包动作名、动作分类 | `renderer/lib/action-i18n.js` | 本机 9 个包共 403 个唯一动作 + GPT娘v1 图集 9 个已覆盖 |
| 角色台词（9 套形象的开场、触摸、喂食、饥饿、睡觉） | `renderer/lib/lines-i18n.js` | 312 条全部覆盖 |
| 默认梗图与经典配文 | `renderer/lib/memes-i18n.js` | 已覆盖 |
| 档案馆 / dsh 图库配文 | `renderer/lib/meme-gallery-i18n.js` | 已覆盖 |
| 托盘菜单、文件选择框、托盘气泡通知 | `wails/i18n.go`、`tray_windows.go` | 跟随语言 |
| 之后新增的包动作名 | 包内清单 | 未命中时回退原文，待 manifest v2 支持自带译名 |

## 实现方式

- 静态文案按**中文原文**映射；未命中时回退中文，不会出现空白。
- 运行时拼接的状态文本（如「40 秒」「已是最新版本 v1.5.3」「下载失败：…」）由 `i18n.js` 的模式规则处理。
- `apply()` 切换语言时先恢复中文原文再翻译；`MutationObserver` 持续处理操作后新写入的提示文本。
- 台词与气泡内容由 `sayNow()` 统一调用 `line()`，避免被界面观察器二次改写。
- 语言保存在 `state.lang`；托盘等原生界面通过原子语言值读取，不阻塞状态锁。

## 添加新台词

1. 在 `renderer/lib/dialogue-data.js` 增加中文原文。
2. 在 `renderer/lib/lines-i18n.js` 的 `EN` / `JA` 中按**完全相同的中文原文**补键。
3. 运行 `npm run test:frontend`，`tests/i18n-lines.test.js` 会逐条检查是否缺失。

## 添加新动作名

- 内置动作：在 `renderer/lib/action-i18n.js` 的 `EN` / `JA` 补键。
- 下载包/扩充包：在 `PACK_EN` / `PACK_JA` 补键；未命中的新动作回退原文。

## 添加新梗图配文

- 默认梗图：改 `renderer/lib/memes-i18n.js`
- 档案馆 / dsh 图库：改 `renderer/lib/meme-gallery-i18n.js`

两个测试会从 `archive-memes.js`、`dsh-memes.js` 直接提取文案并校验，不依赖手工清单。

## 设计约束

- 翻译表是普通 `<script>`，不使用 `fetch` / JSON，避免 CSP 与 `file://` 加载限制。
- `extend()` 只补充台词缺失键，`extendUI()` 只补充界面缺失键，都不覆盖已有译文。
- 动态台词在 `sayNow()` 中统一调用 `line(text, lang)`，所以台词、梗图配文走同一套回退逻辑。
