FAQ

你可能想问。

完整版和 Lite 版有什么区别？

功能完全一致。完整版保留全部原始素材；Lite 版将动画压缩为 480×270、立绘缩到最长边 720，体积更小。两版有独立的安装目录、状态目录和单实例，可以同时安装。

支持哪些 Windows 版本？

Windows 10 / 11 x64。安装包内置 WebView2 在线引导，系统缺少运行时会提示或自动安装；安装和卸载向导均为简体中文。

会读取或上传我的 Qoder 数据吗？

白饭账本只在本机读取 Qoder 会话转录并汇总 credits，不上传原始对话。API Key 使用 Windows DPAPI 加密保存，查询时只发送给对应 AI 平台的官方接口。所有自定义文字都在本机匹配敏感词库。

可以在两台电脑上安装吗？

可以。安装包没有绑定设备；同一台电脑也可以同时安装完整版和 Lite 版。更新检查会按当前版本选择对应安装包，不会让 Lite 下载成完整版。

怎么卸载？

在「Windows 设置 → 应用」中找到「大肥鱼桌宠」或「大肥鱼桌宠 Lite」卸载。用户设置默认保留在 AppData，重新安装后还能接着用。
