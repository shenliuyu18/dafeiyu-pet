FAQ

你可能想问。

完整版和 Lite 版有什么区别？

功能完全一致。完整版内置素材保持原字节，可下载形象包使用 640×360 CRF 32；Lite 版把内置动画压缩为 480×270，形象包自动选择 480×270 版本。两版有独立的安装目录、状态目录和单实例，可以同时安装。

形象包怎么下载？需要另外付费吗？

在「设置 → 形象与音效」里点下载即可，应用会自动在直连与多个镜像之间选最快线路；也可以从素材仓库手动下载 zip 后导入。形象包免费提供，但角色与动作素材有各自的非商业授权，详见下方「开源与许可」。

支持哪些 Windows 版本？

Windows 10 / 11 x64。安装包内置 WebView2 在线引导，系统缺少运行时会提示或自动安装；安装和卸载向导均为简体中文。

会读取或上传我的数据吗？

白饭账本只在本机读取 Qoder 会话转录并汇总 credits，不上传原始对话。API Key 使用 Windows DPAPI 加密保存，查询时只发送给对应 AI 平台的官方接口。所有自定义文字都在本机匹配敏感词库。

可以自己制作形象包吗？

可以。按仓库 docs/形象包制作标准.md 准备 manifest.json 与 640×360 透明 WebM，使用 tools/character-pack 里的脚本校验和打包，再从商店导入。导入时会检查 id、路径、文件与行为槽位。

怎么卸载？

在「Windows 设置 → 应用」中找到「大肥鱼桌宠」或「大肥鱼桌宠 Lite」卸载。用户设置默认保留在 AppData，重新安装后还能接着用。
