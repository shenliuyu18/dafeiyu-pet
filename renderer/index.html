桌宠形象
v1 是逐帧动画版；v2~v6 是表情立绘（各套画风/动作不同）；GPT 娘使用 73 帧透明图集，支持待机、奔跑、挥手、工作、庆祝和 16 方向视线（不带白饭梗与表情包）
音效
点击表情播放顺序
伪随机：每轮把点击表情打乱后依次播放，播完重新洗牌，避免短时间内重复；真随机：每次独立抽取，每个组合概率相等。
尺寸 100%
字体大小 100%
影响气泡、右键菜单与「选个动作」面板的文字大小
待机位置
「固定不动」：先把她拖到想要的位置，她就一直待在那儿
全屏视频 / 游戏
检测到全屏视频、游戏或演示时自动藏起，退出全屏后重新回到其他窗口上方；普通窗口和最大化窗口不受影响。
自动动作间隔 40 秒
每隔该时间随机做一个动作（拖动中、专注中不打扰）
番茄钟时长 25 分钟
开始专注后她会挂倒计时牌安静陪你，时间到再蹦跶提醒你休息
工作动画播放间隔 5 秒
上一个工作动作完整播完后，休息该时间再播下一个（写代码 / 思考 / 忙碌 / 清点）；不会执行其他自动动作
白饭账本
账本来源
选「Qoder credits」读本机用量；选某个 AI 平台则查询该平台的账单（需先配置对应 API Key）。OpenAI / Claude 需要 Admin Key；豆包填「AK:SK」。
API Key 配置
⚠️ 风险提示：API Key 会用 Windows 系统加密（DPAPI）后保存在本机状态文件里，仅本机可解密；查询账单时只会把 Key 发送给对应平台的官方接口。请勿在共用电脑上填写；建议使用只读 / 低额度的 Key；不要把这个状态文件或 Key 发给任何人。是否配置由你自行决定，风险自负。
开机自启动
高优先级自启会让桌宠以 Windows 高进程优先级运行，系统繁忙时更不容易卡顿，但可能影响其他前台程序的响应。
休眠/睡眠恢复
从休眠/睡眠唤醒后检查窗口、置顶和渲染状态；异常时自动重启桌宠并保留设置。主动隐藏桌宠时不会自动恢复。
一起启动的应用 未设置
桌宠启动时会把选中的应用一起打开（exe / 快捷方式均可）
自动更新
开启后每天首次启动会检查更新，发现新版本自动下载、静默安装并重启桌宠
版本 -
检查 GitHub Releases 是否有新版本
点击「GitHub直链下载」或「GitHub加速下载」会自动下载并打开安装程序；安装程序启动前会关闭当前桌宠，安装完成后自动重新打开。国内下载慢时可用蓝奏云网盘（密码 5meo）。
自定义互动文字
每行一句，最多 20 行、每行 40 字。启用后，点击桌宠和闲时碎碎念会优先使用这些话。
还没有自定义文字，当前使用默认台词。

操作说明
单击 摸摸头（随机回应 + 台词） · 双击 喂一碗白饭
拖拽 搬到任意位置 · 右键 打开菜单（喂饭 / 选个动作 / 番茄钟 / 白饭账本 / 状态 / 睡觉 / 设置 / 躲起来 / 退出）
鼠标靠近 她会朝你看 · 约 100 秒不理她会打瞌睡
自动动作 每隔「自动动作间隔」随机表演一个节目（默认 40 秒，可在设置里调）
选个动作 右键菜单里可以点播 100 多个节目；立绘形象会用各自的姿势和动作
自定义互动文字 设置里可写自己的台词（每行一句），保存时会用离线敏感词库检查
待机位置 到处游 / 右下角 / 固定不动（设置里切换）
番茄钟 时长 5~120 分钟可调，专注时她会安静陪你
白饭账本 显示 Qoder 用量，或在设置里配置 API Key 后查询各 AI 平台的余额
托盘图标可以随时叫出/藏起桌宠、打开设置；GPT 娘使用完整图集动画
